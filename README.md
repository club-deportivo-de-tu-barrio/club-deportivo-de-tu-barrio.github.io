# Club Deportivo de tu Barrio · V5

Web estática preparada para publicar en Netlify.

## Contenido
- index.html: portada completa.
- inscripcion-completa.html: ficha digital por pasos + impresión/guardado PDF local.
- privacidad.html: borrador de información de privacidad pendiente de revisión jurídica.
- gracias.html: confirmación de preinscripción.
- imágenes deportivas.
- documentacion/: PDF originales facilitados como referencia.

## Publicación rápida
1. Descomprime esta carpeta.
2. Entra en Netlify Drop: https://app.netlify.com/drop
3. Arrastra la carpeta completa.
4. En el panel de Netlify, comprueba el formulario `preinscripcion`.
5. Configura las notificaciones por email.

## Antes de recibir datos reales
- Sustituir la información de privacidad por el texto definitivo revisado.
- Confirmar el procedimiento para datos de salud de menores.
- Confirmar horarios de béisbol y balonmano.
- Añadir redes sociales reales.
- Añadir IBAN/método de donación cuando el club lo confirme.
- Configurar dominio propio.
- No publicar los PDF originales hasta actualizarlos al nombre/datos del club actual.
