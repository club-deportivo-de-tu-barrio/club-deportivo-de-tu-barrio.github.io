INSCRIPCIONES · MÁLAGA

Tu plaza
empieza aquí.

Hemos diseñado el proceso pensando en las familias: primero una preinscripción sencilla y después una ficha completa organizada por pasos.

✓ Selecciona la actividad
✓ Rellena los datos del menor y tutor/a
✓ Añade autorizaciones y documentación
✓ Revisa antes de enviar
Importante
La ficha puede incluir información sensible, especialmente datos de salud. La versión web separa la solicitud inicial de la documentación completa para evitar enviar información sensible de forma improvisada.
